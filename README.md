# Student Performance Analysis

## Overview

This project analyzes student performance data using Python, Pandas, and Excel-style datasets.

## Features

- Data loading using CSV files
- Student performance analysis
- Average grade calculation
- Top-performing student identification
- Subject-level analysis
- Data visualization using Matplotlib
- Exporting processed datasets

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV Files
